## 🎨 RTL Styling Notes

### Important RTL Adjustments
1. **Icons**: Flip arrow directions (ArrowRight → ArrowLeft for RTL)
2. **Margins/Padding**: Use logical properties (ms-, me- instead of ml-, mr-)
3. **Text Align**: Default to right for RTL
4. **Flex Direction**: Some layouts may need row-reverse
5. **Mobile Menu**: Changed from `side="left"` to `side="right"`

### CSS Classes for RTL
```css
/* Use these for RTL-friendly spacing */
ms-2  /* margin-inline-start */
me-2  /* margin-inline-end */
ps-4  /* padding-inline-start */
pe-4  /* padding-inline-end */
```
