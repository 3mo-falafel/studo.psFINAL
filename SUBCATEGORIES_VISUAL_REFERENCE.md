## 🔄 Data Flow Diagram

```
User Action
    ↓
toggleSubcategory(slug)
    ↓
Update selectedSlugs state
    ↓
useMemo triggers recalculation
    ↓
Filter products array
    ↓
Re-render with filtered products
    ↓
UI updates (instant!)
```
